#Setup

##Artifactory SSL Certificate

Once a common Java environment is used, this step shouldn't be necessary anymore (at least on Linux).

SSL certificate can be fetched using any browser.
Can be imported into the JRE/JDK default certificate store:

    Cert store location:    .\Android Studio\jre\jre\lib\security\cacerts (same structure under Linux)
    Import command: keytool -keystore cacerts -importcert -file desrvaf01_eso_local.crt -alias esoArtifactory

##Artifactory Credentials

Artifactory credentials can be provided via System Properties read from a gradle.properties file in the user local gradle cache:

Create empty file gradle.properties in C:\Users\[user]\.gradle or $HOME/.gradle
Edit file and add the following two lines:

systemProp.artifactory_user=[your username]
systemProp.artifactory_password=[your api key/password]

Fill in your own username and api key/password without brackets.

Using an api key over the domain password should be prefered, as it can be easily revoked and doesn't have to be changed on a regular basis.
An api key can be generated in the Artifactory user profile settings (Authentication Settings -> API Key.
