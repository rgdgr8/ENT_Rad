== Appendix A: Current Test Profile Notes (2026-09-03)

This user manual remains valid for functional test flows. The following clarifications apply to
the current branch:

* Supported development profiles: `emu`, `icc`, `no-gn`
* Selector: `-Pmds.profile=<profile>`

For `no-gn` tests:

* Gracenote license is intentionally disabled (`GN_LICENSE_VARIANT=NONE`, `GN_LICENSE_ENABLED=false`)
* Song text and cover image availability can differ
* A missing image with available text is possible and should be handled as a valid test outcome
