== Appendix A: Current Branch Maintenance Notes (2026-09-03)

This architecture document contains historical evolution across multiple ownership phases.
For current runtime/profile behavior, verify against implementation-level sources:

* `metadataservice/app/build.gradle`
* `scripts/build_all_variants.sh`

Current profile selector in active builds:

* `-Pmds.profile=emu|icc|no-gn`

The `no-gn` profile disables Gracenote licensing (`GN_LICENSE_VARIANT=NONE`) but can still
allow partial metadata on specific runtime paths. Architecture and test interpretations should
separate license state from data-shape completeness.
