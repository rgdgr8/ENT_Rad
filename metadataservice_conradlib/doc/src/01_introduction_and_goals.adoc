== Introduction and Goals

The Connected Radio Client is one of the major parts of the MetaDataService software element.
The Client serves as the connecting part between the MetaDataService and the Connected Radio backend.
This means that several data which is transferred between the backend and the MetaDataService application is prepared and processed by the Connected Radio Client.
The connected radio client is an important background service which is not visible directly for the user.
The only goal of the connected radio client is to get and provide new data to the MetaDataService application from the backend e.g. logos of radio channels or other information about the radio channels.

=== Requirements Overview

All relevant requirements can be found in Polarion by filtering for the software element metadataservice_conradlib.

=== Quality Goals

The Connected Radio Client is only used from the MetadataService App and is connected to our self developed and hosted backend systems. +
In this case it is necessary to achieve the following quality goals:

* *Secure Connection* +
Use modern technologies to ensure the connection to the backend is safe for external intervention

* *Save data volume* +
Reduce the size of the send data to and from the backend to us as little data volume as possible

* *Reduce number of requests* +
Use mechanism ro avoid the backend from to many requests and for to big requests at once.

* *Retry failed requests in a controlled way* +
Find a way to retry failed requests with the minimum of delay for the customer but enough time for the backend to be ready for the next request.
