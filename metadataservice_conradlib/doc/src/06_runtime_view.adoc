== Runtime View

=== Startup

We are a part of the metadataservice app which is a system app. These app start if some other app have a description to them.
Our lib is initiate from the metadataservice during her startup. After initiation, we start a request to the backend to update our default config values.

=== Shutdown

The metadataservice will be shutdown from the system if nobody use the service. We do nothing for the shutdown.

=== Suspend

We do not react to Suspend2Ram.

=== Resume

We do nothing special after resume from Suspend2Ram. If we notice during our first backend request that the cookie is expired we start a new registration request identical to the startup request.

[[Async]]
=== Asynchronous calls

When the Method `getRadioStationData` is called, the requested bearer is sent to the RequestController.
If the limit is reached or no other bearer request is received in the configured time, the request job will be created and send to the worker queue.
The worker takes the first element in the queue, checks the registration and starts the request to the backend.
The received data from the backend will be parsed and sent to media using the given callback instance.
If required, a logo request will be made to receive the radio station image.
At the end the `onComplete` callback function is called and the coroutine ends.
