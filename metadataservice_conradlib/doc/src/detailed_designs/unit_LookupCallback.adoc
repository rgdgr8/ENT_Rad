[unit=LookupCallback, role=unit]
== <<Unit>> LookupCallback
This document specifies the design of the unit *LookupCallback*, it is part of the link:../../main.{type}[metadataservice_conradlib].

The unit is responsible to evaluate the response from the backend and passes this information to link:unit_SendToMedia.adoc[SendToMedia].

This class implements the okhttp3.Callback interface,
the implemented functions will be called by the okhttp threads after finishing the request process.

== Provided Interface (public methods and properties)

=== LookupCallback.class(lookupRequests: Map<String, MediaRequestObject>, mcc: String?, requestAvailableImage: (MediaRequestObject) -> Unit): LookupCallback

The constructor receives some information about the request and has to save it for later processing.

*Arguments*

|===

|Map<String, MediaRequestObject>
|One or more entries
|Data that must be included in the request. Key is the bearer string and value the request data and callbacks.

=== LookupCallback.onFailure(call: Call, e: IOException)

If it is not possible to send the request because of network problems, this callback will be triggered from OkHttp.
The function has to trigger SendToMedia.errorForAll with RetryBehavior.DELAYED for all given bearers.

*Arguments*

|===
|name|value range |valid values | description

|okhttp3.Call
|okhttp3.Call
|Information about the OkHTTP request call.

|e
|java.io.IOException
|java.io.IOException
|The exception that occurred while sending the request.
|===

*Return*

None

*Exceptions*

None

=== LookupCallback.onResponse(call: Call, response: Response)

This function will be triggered if the client receives a response from the backend,
it contains the primary logic of this unit.

The function must handle the response by this status code behaviors:

- 200/207 - See successful response behavior definition
- 204 - Call SendToMedia.noContentForAll()
- 304 - Call SendToMedia.notModifiedForAll()
- 429/503 - See error retry after response definition
- else - See error retry after response definition but skip step 1

Successful response behavior:

1. Parse the response body by GenericMoshiParser.parseFromJson<Map<String, LookupResult>>
- If failed or no content then call SendToMedia.errorForAll() with RetryBehavior.ONCE
2. Foreach over the response entries
- If entry was not in request then call SendToMedia.error() with RetryBehavior.DELAYED
3. Handle every response entry by the json status code
- 200
* If no data given then call SendToMedia.error() with RetryBehavior.DELAYED
* Call SendToMedia.metadata() with the data from the parsed json body
* If logo value is null then call SendToMedia.deleteLogo()
* If logo value is not given in response then call SendToMedia.notModified()
* If logo value is given then call the image callback given in the class constructor
- 204 - Call SendToMedia.noContent()
- 304 - Call SendToMedia.notModified()
- 202/400/422 - Call SendToMedia.retryAfterOrBackendPreferences() with the retryAfter value in the json and the backend preferred retryBehavior and contentExpiry.
- else - Call SendToMedia.error() with RetryBehavior.NONE

Error retry after response behavior:

1. If Retry-After header is available then call ServerDowntimeHandler.setServerDowntime() with the header value
2. Trigger SendToMedia.retryAfterOrBackendPreferencesForALl() by the delay given in the Retry-After header or otherwise use the default retryDelay of 30L. Also use the backend preferred retryBehavior (if not available use RetryBehavior.NONE) and contentExpiry if available.

*Arguments*

|===
|name|value range |valid values| description

|call
|okhttp3.Call
|okhttp3.Call
|Information about the OkHTTP request call.

|response
|okhttp3.Response
|okhttp3.Response
|The response instance that contains the data from the backend.
|===

*Return*

None

*Exceptions*

None

== Runtime View

No explicit specification required, because no startup logic exists.

The calling unit must simply remove all references to this instance,

=== Response handling

[plantuml, title="onResponse()", format="svg", id="onResponse"]
----
participant "Arbitrary Unit" as caller
participant "LookupCallback" as callback <<unit>>
participant "SendToMedia" as media <<unit>>
participant "GenericMoshiParser" as parser <<unit>>
participant "ServerDowntimeHandler" as downtime <<unit>>

caller -> callback
activate callback

alt Status code is 200 or 207
callback -> parser: parseFromJson()
activate parser
callback <- parser: Response data as kotlin objects
deactivate parser

loop Foreach response entry
alt Response body status code is 200
callback -> media: metadata()
alt Response contains logo id
callback -> callback: Trigger logo available callback
else Response contains logo of null
callback -> media: deleteLogo()
else Response does not contain logo information
callback -> media: notModified()
end

else Response body status code is 204
callback -> media: noContent()

else Response body status code is 304
callback -> media: notModified()

else Response body status code is 202 Or 400 Or 422
callback -> media: retryAfterOrBackendPreferences()

else
callback -> media: error() with RetryBehavior.NONE

end
end

else Status code is 204
callback -> media: noContentForAll()

else Status code is 304
callback -> media: notModifiedForAll()

else Status code is 429 or 503
alt Retry-After header is set in response
callback -> downtime: setServerDowntime()
end
callback -> media: retryAfterOrBackendPreferencesForAll()

else
callback -> media: retryAfterOrBackendPreferencesForAll()

end
deactivate callback
----
