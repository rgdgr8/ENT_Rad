[unit=SendToMedia,role=unit]
== <<Unit>> SendToMedia

This document specifies the design of the unit *SendToMedia*, it is part of the link:../../main.{type}[metadataservice_conradlib].

This kotlin object (Singleton) is responsible to format data into the given link:unit_IRadioStationDataCallback.adoc[IRadioStationDataCallback] format and gives the data to the interface by function calls.

== Provided Interface (public methods and properties)

=== SendToMedia.metadata(logInfo: LogInfo?, mcc: String?, eTags: ETagResult?, data: DataObject, callback: IRadioStationDataCallback)

Uses following functions to create data holder objects and call the related callback functions:

- IRadioStationDataCallback.onMetadata
* ProviderIdentifier.createListFromBackendData
* StationMetadata.createFromBackendData

- IRadioStationDataCallback.onStreams
* WebStream.createListFromBackendData

- IRadioStationDataCallback.onBearers
* IBearer.createListFromBackendData

In case the backend does not send a stream or bearer, the related callback should not get triggered.
If the backend does not send a list, the variable of the data holder is null.

*Arguments*

|===
|name|value range |valid values | description

|logInfo
|LogInfo?
|LogInfo or null
|The log info that should be used to write logs or null if not available.

|mcc
|String?
|The MCC as String or null if no MCC got sent.
|The mcc string used for the lookup request, to generate the bearer instances.

|eTags
|ETagResult?
|ETagResult or null
|The ETags received from the backend or null if not available.

|data
|DataObject
|DataObject-Instance
|The station data recieved from the backend.

|callback
|IRadioStationDataCallback
|IRadioStationDataCallback-Instance
|The callback to whom the data should be given.
|===

*Return*

None

*Exceptions*

None

=== SendToMedia.logo(logInfo: LogInfo?, etag: String?, stationLogo: StationLogo, callback: IRadioStationDataCallback, contentExpiry: Long?)

Send the received logo to the callback via the onLogo function and finish the process with onComplete.

Call the onComplete with

- CompleteStatus
* retry = RetryBehavior.NONE
* retryDelaySeconds = null
- expirationDate
* Current UTC time + contentExpiry

*Arguments*

|===
|name|value range |valid values | description

|logInfo
|LogInfo?
|LogInfo or null
|The log info that should be used to write logs or null if not available.

|etag
|String?
|ETag String or null
|The ETag string received from the backend or null if not available.

|stationLogo
|StationLogo
|StationLogo-Instance
|The logo data that should be sent to the callback.

|callback
|IRadioStationDataCallback
|IRadioStationDataCallback-Instance
|The callback to whom the data should be given.

|contentExpiry
|Long?
|Long or null
|The backend preferred content expiry that shall be sent to media.
|===

*Return*

None

*Exceptions*

None
