[unit=Http, role=unit]
== <<Unit>> Http
This document specifies the design of the unit *Http*, it is part of the link:../../main.{type}[metadataservice_conradlib].

The OkHttp client is responsible to send requests to the backend with defined security settings.
The http client must be implemented as kotlin object (Singleton).
It has to support cookies and use CookiePolicy.ACCEPT_ALL.

It should use following timeouts:

- Call timeout: 40s
- Read timeout: 20s
- Write timeout: 20s
- Connect timeout: 10s

For the connection following security settings from the CARIAD spec should be used:

- ConnectionSpec.MODERN_TLS
- TLS Version
* TlsVersion.TLS_1_2
* TlsVersion.TLS_1_3
- Cipher suites
* CipherSuite.TLS_ECDHE_ECDSA_WITH_CHACHA20_POLY1305_SHA256
* CipherSuite.TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384
* CipherSuite.TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256
* CipherSuite.TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384
* CipherSuite.TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256
* CipherSuite.TLS_DHE_RSA_WITH_AES_256_GCM_SHA384
* CipherSuite.TLS_DHE_RSA_WITH_AES_128_GCM_SHA256
* CipherSuite.TLS_AES_256_GCM_SHA384
* CipherSuite.TLS_CHACHA20_POLY1305_SHA256
* CipherSuite.TLS_AES_128_GCM_SHA256

We want to improve the logging of the http client,
so the LogJavaNetCookieJar wrapper around a JavaNetCookieJar should be implemented and used.
This class that implements the CookieJar interface, should log all changes to cookies to the Logger.

To use only specified networks, we have to implement our own network dns by a Dns interface.
This class should use the given network to resolve hostnames.
If no network is given, it should use the default system dns.

== Runtime View

[dynamic_sequence=startup, unit=Http, role=dynamic_sequence]
=== Startup

At Http class initialisation, it should initialize the OkHttp client with the specified settings.

[dynamic_sequence=shutdown, unit=Http, role=dynamic_sequence]
=== Shutdown

The Http class is a kotlin object (Singleton) that will stay in the memory forever, so it can be reused.

[dynamic_sequence=startup_after_s2r, unit=Http, role=dynamic_sequence]
=== Suspend

Since this is a kotlin class without deep android references, no suspend state needs to be considered.

[dynamic_sequence=resume, unit=Http, role=dynamic_sequence]
=== Resume

Since this is a kotlin class without deep android references, no suspend state needs to be considered.
