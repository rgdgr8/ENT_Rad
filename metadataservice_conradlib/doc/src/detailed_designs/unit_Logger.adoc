[unit=Logger,role=unit]
== <<Unit>> Logger

This document specifies the design of the unit *Logger*, it is part of the link:../../main.{type}[metadataservice_conradlib].

The logger is responsible to write information to the eso traces to find bugs and understand the client behavior.
The Logger class is a kotlin object (Singleton).

Built the log message like this:

1. If bearer is not null, bearer representation in square brackets
2. Message
3. LoggerTags seperated by blank character
4. Request id prefixed by "#request:"
5. "#crc"

If writing traces fails, write the log message via kotlin println and prepend:

1. Timestamp
2. Level name
3. Privacy flag name

=== PrivacyFlags.class(val privacyFlag: PrivacyFlag)

This enum class defines which message should be logged with which PrivacyFlag of the eso framework.

*Arguments*

|===
|name|value range |valid values | description

|privacyFlag
|PrivacyFlag
|PrivacyFlag
|The PrivacyFlag that should be given to the eso framework for specific log messages.
|===

*Enums*

|===
|name|privacyFlag|description

|SAFE
|PrivacyFlag.NOT_CATEGORIZED
|Should be used when the logged data does not match to any other PrivacyFlag.

|TOKEN
|PrivacyFlag.UNIQUE_ID
|Should be used when a token used for authentication is logged.
A token is a unique identifier for authentication with the backend.
Therefore, it should be logged as UNIQUE_ID.

|SESSION
|PrivacyFlag.UNIQUE_ID
|Should be used when a session is logged.
A session is a unique identifier used to identify a session.
Therefore, it should be logged as UNIQUE_ID.

|UNDECIDED
|PrivacyFlag.CATEGORY_UNDECIDED
|Should be used if the logged data is unknown or the data has not been checked to which PrivacyFlag it belongs.
|===
