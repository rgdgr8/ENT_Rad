[unit=LookupRequestJob,role=unit]
== <<Unit>> LookupRequestJob

This document specifies the design of the unit *LookupRequestJob*, it is part of the link:../../main.{type}[metadataservice_conradlib].

This job class is responsible to send and evaluate requests to the lookup endpoint, the endpoint is responsible to receive meta information about radio stations.

The class has to implement the link:unit_IJob.adoc[IJob] interface.

== Provided Interface (public methods and properties)

=== LookupRequestJob.class(container: Map<String, MediaRequestObject>, mcc: String?, registrationHandler: HandleRegistration, tokenHandler: TokenHandler): LookupRequestJob

The constructor receives the data and handler instances that are required to send backend requests that meet the requirements.

*Arguments*

|===
|name|value range |valid values | description

|container
|Map<String, MediaRequestObject>
|One or more entries
|Data that must be included in the request. Key is the bearer string and value the request data and callbacks.

|mcc
|String?
|String that contains a MCC or null
|The MCC that must be sent to the backend to resolve the bearers.

|registrationHandler
|HandleRegistration
|HandleRegistration
|The handler that must be used to ensure the registration is still valid.

|container
|TokenHandler
|TokenHandler
|The handler that must be used to receive tokens for backend requests.
|===

=== LookupRequestJob.run()

This function runs the primary job logic, it has to do the following:

1. Check if link:unit_ServerDowntimeHandler.adoc[ServerDowntimeHandler.getRemainingDowntime()] reports downtime
- Call SendToMedia.retryAfterForAll for all bearers
- Return this function
2. Use HandleRegistration.ensureRegistration() to ensure the registration is valid
- On RegistrationFailureException call SendToMedia.error() with RetryBehavior.DELAYED if responseCode is null, else call SendToMedia.retryAfterOrBackendPreferences() with the backend preferred retryBehavior and contentExpiry. Use retryBehavior.EXPONENTIAL as a fallback if no backend preferred retryBehavior is available. On other exceptions call SendToMedia.error() with RetryBehavior.EXPONENTIAL.
- Return this function on exception
3. Use the link:unit_TokenHandler.adoc[TokenHandler.getToken()] to receive a backend token
- If it fails then use SendToMedia.errorForAll and return this function
4. Build a request body
- Use link:unit_GenericMoshiParser.adoc[GenericMoshiParser.parseToJson()] for JSON parsing
- Use StationInformation and ETagRequest as data models
5. Build the request headers
- Set RequestHeader.accept to "application/json"
- Set RequestHeader.mcc to the MCC given in the constructor
6. Build LookupCallback
- The logo available callback must create a LogoRequestJob and enqueue it onto the ExecutorWorker
7. Start async request to the backend by Http.enqueuePost

The function has to guarantee that the callback will be executed or the bearer will directly be answered at SendToMedia.

*Arguments*

None

*Return*

None

*Exceptions*

None

*Special attributes*

** async: Starts async http request, the result must be handled by a callback.

== Runtime View

[dynamic_sequence=startup,unit=LookupRequestJob,role=dynamic_sequence]
=== Startup

No explicit specification required, because no startup logic exists.
The job logic will start by the run() function.

[dynamic_sequence=shutdown,unit=LookupRequestJob,role=dynamic_sequence]
=== Shutdown

The calling unit must simply remove all references to this instance,
which causes the kotlin garbage collector to remove it from the heap.

[dynamic_sequence=startup_after_s2r,unit=LookupRequestJob,role=dynamic_sequence]
=== Suspend

Since this is a kotlin class without android references, no suspend state needs to be considered.

Since this is a kotlin class without android references, no suspend state needs to be considered.

=== Handle registration failure

[plantuml, title="run() but registration failure", format="svg", id="run-registration-failure"]
----

participant "Arbitrary Unit" as caller
participant "LookupRequestJob" as job <<unit>>
participant "ServerDowntimeHandler" as downtime <<unit>>
participant "HandleRegistration" as registration <<unit>>
participant "SendToMedia" as media <<unit>>

caller -> job: run()

job -> downtime: getRemainingDowntime()
activate downtime
job <- downtime: null
deactivate downtime

job -> registration: ensureRegistration()
activate registration
job <- registration: Throw RegistrationFailureException
deactivate registration

alt exception.responseCode == null
    job -> media: errorForAll(RetryBehavior.DELAYED)
    job -> caller: return
else
    job -> data: getBackendPreferredRetryBehavior(responseCode, RetryBehavior.EXPONENTIAL)
    job -> data: getBackendPreferredContentExpiry(responseCode)
    job -> media: retryAfterOrBackendPreferencesForAll()
    job -> caller: return
end
----
