[unit=IRC, role=unit]
== <<Unit>> IRC
This document specifies the design of the unit *IRC*, it is part of the link:../../main.{type}[metadataservice_conradlib].

The IRC is responsible to record errors and important information in production cars.
If there is an RuntimeException while writing messages, it should write a log to the link:unit_Logger.adoc[Logger].
The IRC class should be a kotlin object (Singleton).

== Provided Interface (public methods and properties)

=== IRC.printVersionInformation()

Should write the client version from the BuildConfig into the IRCEntry.VERSION channel.
Use IRC.getIRC().logUsage() from the eso framework to write this message.

*Arguments*

None

*Return*

None

*Exceptions*

None

=== IRC.error(entry: IRCEntry, message: String)

Write the first 128 characters from the message to the given irc channel.
Use IRC.getIRC().logSystem() from the eso framework to write this message.

*Arguments*

|name|value range |valid values | description

|entry
|IRCEntry
|IRCEntry
|The irc channel that should receive the message.

|String
|String with max 128 characters
|The message that should be written to the irc channel.
|===

*Return*

None

*Exceptions*

None

== Runtime View

[dynamic_sequence=startup, unit=IRC, role=dynamic_sequence]

No explicit specification required, because no constructor or startup logic exists.

This class is a kotlin object (Singleton) that will stay in the memory forever, so it can be reused.
