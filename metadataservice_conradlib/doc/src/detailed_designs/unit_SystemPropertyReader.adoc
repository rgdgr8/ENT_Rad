[unit=SystemPropertyReader, role=unit]
== <<Unit>> SystemPropertyReader
This document specifies the design of the unit *SystemPropertyReader*, it is part of the link:../../main.{type}[metadataservice_conradlib].

This class is responsible to read system information from the android.os.SystemProperties, it must use reflections to call the get() function from android to receive the property values.

It should only read system properties once, then it must cache the value internally.

== Provided Interface (public methods and properties)
