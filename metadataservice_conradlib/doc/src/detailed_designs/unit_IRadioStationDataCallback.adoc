== <<Unit>> IRadioStationDataCallback
This document specifies the design of the unit *IRadioStationDataCallback*, it is part of the link:../../main.{type}[metadataservice_conradlib].

This callback interface is used to give the requested data to the MetaDataService.

== Provided Interface (public methods and properties)

=== IRadioStationDataCallback.onMetadata(etag: String?, metadata: StationMetadata?)

Called if an answer from the backend was received, the function reports the station metadata about the requested bearer.

*Arguments*

|===
|name|value range |valid values | description

|etag
|String?
|String or null
|The etag received from the backend or null if no data is available.

|metadata
|StationMetadata?
|StationMetadata or null
|The station metadata received from the backend or null if no data is available.
|===

*Return*

None

=== IRadioStationDataCallback.onComplete(status: CompleteStatus, expirationDate: Long?)

It must always call this function after a bearer request finishes
(regardless of whether this is successful or faulty).

If expirationDate is null the bearer will be requested at the next client request.
Should only send expirationDate, if the request was successfully.

*Arguments*

|===
|name|value range |valid values | unit | description

|status
|CompleteStatus
|CompleteStatus-Instance
|n/a
|Defines the retry behavior of the MDS.

|expirationDate
|Long?
|1 or more, null
|UTC timestamp in seconds
|How long the MetaDataService should cache the data, without requesting again at the connected radio client.
|===

*Return*

None
