== <<Unit>> IJob
This document specifies the design of the unit *IJob*, it is part of the link:../../main.{type}[metadataservice_conradlib].

This interface has the purpose of implementing different jobs that can be queued and executed by the link:unit_ExecutorWorker.adoc[ExecutorWorker].

The kotlin interface implementation should inherit from java.lang.Runnable.

== Provided Interface (public methods and properties)

=== IJob.run()

This function is called by the ExecutorWorker and should execute the purpose of the implementation class.

*Arguments*

None

*Return*

None
