[unit=IController, role=unit]
== <<Unit>> IController
This document specifies the design of the unit *IController*, it is part of the link:../../main.{type}[metadataservice_conradlib].

This interface has the purpose of implementing different controllers that can accept and respond to the incoming requests.

== Provided Interface (public methods and properties)

=== IController.getRadioStationData(mediaRequestObject: MediaRequestObject)

*Arguments*

|===
|name|value range |valid values | description

|mediaRequestObject
|MediaRequestObject
|MediaRequestObject-Instance
|The received MediaRequestObject object that should be answered by this controller.

|===


*Return*

None

*Exceptions*

None

*Special attributes*

** async: If IO becomes necessary, the callback should be answered asynchronously.
** timing: Should not put the caller thread to sleep or do IO in sync, this function should end quickly.
