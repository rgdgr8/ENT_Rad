[unit=Debug, role=unit]
== <<Unit>> Debug
This document specifies the design of the unit *Debug*, it is part of the link:../../main.{type}[metadataservice_conradlib].

The debug unit is for better testing in the MetaDataService app, it is not costumer relevant.
It should not send any backend requests, instead it must generate random or hardcoded data.
Here we implement a controller that that uses some util classes to generate random values and give them to the callback.

== Provided Interface (public methods and properties)

=== DebugController.class(): DebugController

This is the primary class of the unit, it has to implement the IController interface.

*Arguments*

None

=== DebugController.getRadioStationData(mediaRequestObject: MediaRequestObject)

This function has to call functions from the given callback as specified with random behavior and random data.
It must use the settings from the given DebugConfig for better control.

For a specified probability it has to answer requests with an error behavior,
that means that no data callbacks are triggered and onComplete() contains a retry behavior of not-NONE.

No matter how the random effect decides, the controller behavior must always be as specified.
This means that the complete callback must always be called at the end.

Between callback calls it has to sleep a random delay, the min and max delay is configured in the DebugConfig.

*Arguments*

|===
|name|value range |valid values| description

|mediaRequestObject
|MediaRequestObject
|MediaRequestObject
|The request we received from the app.
|===

*Return*

None

=== DebugConfig.class()

This is a class that contains many editable variables to configure the behavior of the DebugController.

*Variables*

|===
|name|type|valid values|default|description

|minDelay|Int|0 or more|0|Between every callback call, wait a random delay with a minimum of the here configured seconds.
|maxDelay|Int|0 or more|1|Between every callback call, wait a random delay with a maximum of the here configured seconds.
|sendError|Double|Percent value between 0 and 1|0.0|How many requests should be answered with error (no data and retry).
|sendSLogo|Double|Percent value between 0 and 1|1.0|How many requests should receive slogo calls.
|sendLogo|Double|Percent value between 0 and 1|1.0|How many requests should receive logo calls.
|sendMetadata|Double|Percent value between 0 and 1|1.0|How many requests should receive metadata calls.
|sendWebStreams|Double|Percent value between 0 and 1|1.0|How many requests should receive streams calls.
|sendBearerList|Double|Percent value between 0 and 1|1.0|How many requests should receive bearer calls.
|deleteSLogo|Boolean|true or false|false|If true it sends null to the slogo callback, otherwise random data.
|deleteLogo|Boolean|true or false|false|If true it sends null to the logo callback, otherwise random data.
|deleteMetadata|Boolean|true or false|false|If true it sends null to the metadata callback, otherwise random data.
|deleteWebStreams|Boolean|true or false|false|If true it sends null to the streams callback, otherwise random data.
|deleteBearerList|Boolean|true or false|false|If true it sends null to the bearer callback, otherwise random data.
|expireInSeconds|Long|0 or more|86400L|The expiry that will be given to the callback via onComplete().
|===

== Runtime View

[dynamic_sequence=startup, unit=Debug, role=dynamic_sequence]
=== Startup

This unit has no explicit startup logic, the entry point is the DebugController class.

[dynamic_sequence=shutdown, unit=Debug, role=dynamic_sequence]
=== Shutdown

The calling unit must simply remove all references to this instance,
which causes the kotlin garbage collector to remove it from the heap.

[dynamic_sequence=startup_after_s2r, unit=Debug, role=dynamic_sequence]

=== Request RadioStationData from the DebugController

[plantuml, title="getRadioStationData()", format="svg", id="getRadioStationData"]
----
participant "Arbitrary Unit" as caller
participant "DebugController" as controller
participant "IRadioStationDataCallback" as callback

caller -> controller: setDebugConfig()

caller <- callback: Initialize interface implementation

caller -> controller: getRadioStationData()
activate controller

alt If randomizer decided error case
controller -> callback: onComplete() with RetryBehavior
else
controller -> callback: onMetadata() with generated data
controller -> callback: onLogo() with generated data
controller -> callback: onSLogo() with generated data
controller -> callback: onStreams() with generated data
controller -> callback: onBearers() with generated data
controller -> callback: onComplete() without RetryBehavior
end

deactivate controller
----
