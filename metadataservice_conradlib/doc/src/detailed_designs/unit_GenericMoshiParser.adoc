[unit=GenericMoshiParser, role=unit]
== <<Unit>> GenericMoshiParser
This document specifies the design of the unit *GenericMoshiParser*, it is part of the link:../../main.{type}[metadataservice_conradlib].

This class is responsible to use the Moshi parser library and so on parse JSON to objects and vise versa.
It should be implemented as kotlin object (Singleton).

== Provided Interface (public methods and properties)

=== GenericMoshiParser.parseToJson(data: T): String

This generic function should parse the given objects to a json string by using the Moshi parser library.

*Arguments*

|===
|name|value range |valid values | description

|data
|Any class
|Any class
|The instance that should be serialized to a json string.
|===

*Return*

|===
|Type|value range |valid values | description

|Response
|String
|String that contains a JSON
|Object as JSON
|===

*Exceptions*

None

=== GenericMoshiParser.parseFromJson(json: String, parameterizedType: ParameterizedType? = null): T?

This generic function should parse the given string to objects by using the Moshi parser library.

*Arguments*

|===
|name|value range |valid values|default | description

|json
|String
|String that contains a JSON
|n/a
|The instance that should be serialized to a json string.

|parameterizedType
|java.lang.reflect.ParameterizedType?
|java.lang.reflect.ParameterizedType or null
|null
|List of object types if there are not defined by the generic function types or null if not required for parsing.
|===

*Return*

|===
|Type|value range |valid values | description

|Response
|T?
|Any class or null
|Returns the parsed objects or null if parsing failed.
|===

*Exceptions*

None

== Dependencies (Used Units, methods and properties)

No dependencies to other units, only the Moshi parser library is required.
