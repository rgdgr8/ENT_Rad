== <<Unit>> PausableThreadPoolExecutor
This document specifies the design of the unit *PausableThreadPoolExecutor*, it is part of the link:../../main.{type}[metadataservice_conradlib].

This class extends the java.util.concurrent.ThreadPoolExecutor and adds the functionality of pausing the job worker.

== Provided Interface (public methods and properties)

=== PausableThreadPoolExecutor.class(corePoolSize: Int, maximumPoolSize: Int, keepAliveTime: Long, unit: TimeUnit, blockingQueue: BlockingQueue<Runnable>): PausableThreadPoolExecutor

The constructor should not be different to the parent class,
so it should accept the same parameter as ThreadPoolExecutor.

*Arguments*

|===
|name|value range |valid values |resolution |unit | description

|corePoolSize
|Int
|0 or more
|+-1
|n/a
|The number of threads to keep in the pool, even if they are idle.

|maximumPoolSize
|Int
|1 or more
|+-1
|n/a
|The maximum number of threads to allow in the pool.

|keepAliveTime
|Long
|0 or more
|+-1
|Configured by the unit parameter.
|When the number of threads is greater than the core, this is the maximum time that excess idle threads will wait for new tasks before terminating.

|unit
|TimeUnit
|TimeUnit-Instance
|n/a
|n/a
|The time unit for the keepAliveTime argument.

|blockingQueue
|BlockingQueue<Runnable>
|BlockingQueue<Runnable>
|n/a
|n/a
|The queue to use for holding tasks before they are executed. This queue will hold only the Runnable tasks submitted by the execute method.

|===

*Exceptions*

- IllegalArgumentException
* corePoolSize < 0
* keepAliveTime < 0
* maximumPoolSize <= 0
* maximumPoolSize < corePoolSize

=== PausableThreadPoolExecutor.pause()

Stops the worker from beginning new jobs until resume() is called.

*Arguments*

None

*Return*

None

*Exceptions*

None

*Special attributes*

** async: This function should not block the caller thread.

=== PausableThreadPoolExecutor.resume()

Starts executing jobs on the worker, if it was stopped before by pause().

*Arguments*

None

*Return*

None

*Exceptions*

None

*Special attributes*

** async: This function should not block the caller thread.

=== PausableThreadPoolExecutor.isPaused(): Boolean

Checks if the executor is at the moment paused.

*Arguments*

None

*Return*

|===
|Name|value range |valid values |resolution | description

|Response
|Boolean
|Response instance
|true, false
|Returns true if the executor is paused and will not begin running jobs, otherwise false-
|===

*Exceptions*

None
