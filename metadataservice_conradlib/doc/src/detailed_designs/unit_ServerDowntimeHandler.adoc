[unit=ServerDowntimeHandler, role=unit]
== <<Unit>> ServerDowntimeHandler
This document specifies the design of the unit *ServerDowntimeHandler*, it is part of the link:../../main.{type}[metadataservice_conradlib].

This class is implemented as kotlin object (Singleton),
it is a middleware that checks if the server has downtime and would no longer like request from clients,
The HTTP callback decides, if a downtime is currently taking place and reports it to this class.

== Provided Interface (public methods and properties)

=== ServerDowntimeHandler.handleResponse(retryAfter: Long?)

Handles the response from the server and sets the server downtime if a 'Retry-After' header is present. This function is intended to be used for status codes 429 (Too Many Requests) and 503 (Service Unavailable).

*Arguments*

|===
|name|value range |valid values |resolution |unit | description

|seconds
|Long
|1 or more
|+-1
|Seconds
|Duration how long the middleware should mark the backend as not available.

|===

*Return*

None

*Exceptions*

None

=== ServerDowntimeHandler.setServerDowntime(seconds: Long)

Mark the backend as not available for the given duration.

*Arguments*

|===
|name|value range |valid values |resolution |unit | description

|seconds
|Long
|1 or more
|+-1
|Seconds
|Duration how long the middleware should mark the backend as not available.

|===

*Return*

None

*Exceptions*

None

=== ServerDowntimeHandler.getRemainingDowntime(): Long?

Check if the backend is currently marked as down and return the remaining downtime for this client.

*Arguments*

None

*Return*

|===
|Type|value range |valid values |resolution |unit | description

|Response
|Long or null
|1 or more, null
|+-1
|Seconds
|Returns the remaining downtime or null, if no downtime was reported.
|===

*Exceptions*

None
