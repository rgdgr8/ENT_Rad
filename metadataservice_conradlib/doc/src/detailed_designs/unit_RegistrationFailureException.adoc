[unit=RegistrationFailureException, role=unit]
== <<Unit>> RegistrationFailureException
This document specifies the design of the unit *RegistrationFailureException*, it is part of the link:../../main.{type}[metadataservice_conradlib].

This exception class is to clarify that the registration failed.
It must extend the java Exception class and give "Backend registration failed" to the parent constructor as message.

== Provided Interface (public methods and properties)

=== RegistrationFailureException.responseCode

The response code that was returned by the backend or null if no response from the backend was received.
The variable must be of type Int or null.
It must be final, so no one can change it after the class was initialized.

[,kotlin]
----
val retryAfter: Long?
----

=== RegistrationFailureException.retryAfter

The retry after value that was returned by the backend or null if the header is not specified.
The variable must be of type Long or null.
It must be final, so no one can change it after the class was initialized.

[,kotlin]
----
val retryAfter: Long?
----

=== RegistrationFailureException.class(responseCode: Int?, retryAfter: Long?)

The constructor should set the responseCode and retryAfter variables and call the parent constructor.

*Arguments*

|===
|name|value range |valid values |resolution |unit | description

|retryAfter
|Long or null
|1 or more, null
|+-1
|Seconds
|The received retry after header value.

|responseCode
|Int or null
|Http status code, null
|n/a
|Http status code
|The received http status code.
|===
